# DFS 兄弟分支位并行：语义验证原型

这个实验核对 [并行枚举分析](../parallel-enu-analysis.md) 第 6.1 节的两个不同机制：

1. **位切片批执行**：一个 bit 表示一条分支；按顶点组织 lane masks，用 AND 同时更新多个孩子的 P/X。
2. **精确状态合并**：仅当同一批内的 P 和 X 都完全相同时，共享后续搜索；保留每条原始路径的独立 prefix label，最终逐个输出完整 clique。

第三个实现是普通单状态 bitset Bron–Kerbosch。三者使用同样的最大分数 pivot、打平规则和 ext 顺序。每个孩子都应用自己的 earlier-ext 前缀；候选全零不被当作失败，只有 P/X 同时为空才输出。

## 运行

需要 Python 3.10+，无第三方依赖。在仓库根目录执行：

```bash
python3 enumeration/experiments/sibling_bitwise_mce.py \
  --output enumeration/experiments/sibling-bitwise-results.json
```

默认遍历 n=1…5 的全部 1,099 个带标号无向简单图，另生成固定 seed 的 300 个 n=6…10 随机图；比较批宽 1、2、4、8、64，以及启用/禁用精确状态合并两种模式。所有结果与独立的“枚举全部点子集并检查 clique 与全局极大性”oracle 比较。

检查完整结果集合、重复输出和逻辑状态数量。对仅批执行的版本，物理状态数还必须与普通 BK 相同。实验采用 `assert`，请勿使用会禁用断言的 `python -O`。

## 已运行结果

结果文件：[sibling-bitwise-results.json](sibling-bitwise-results.json)。2026-10-17 默认配置通过了 **13,990 次批配置结果比较**，另外检查了三个说明性图。

| 图 | 结果数 | 普通 BK 状态 | 仅位切片状态 | 精确 P/X 合并后的物理状态 | 完整输出顶点 ID 数 |
|---|---:|---:|---:|---:|---:|
| 三角形加一条叶边 | 2 | 5 | 5 | 5 | 5 |
| K₈ | 1 | 9 | 9 | 9 | 8 |
| 完全三部图 K₃,₃,₃ | 27 | 40 | 40 | 4 | 81 |

表中合并版本采用批宽 64。最后一个例子说明精确相同状态可共享后续计算；**40→4 是物理递归状态数，不是实测 10 倍加速**。它仍展开 27 个结果、81 个顶点 ID。K₈ 没有相应收益，说明图密并不自动意味着可合批子树多。

## 实现边界

- 这是 Python 语义原型，packing/unpacking 和邻接掩码构造均为标量循环，没有多线程、SIMD intrinsic 或 GPU 实现，不报告性能优势。
- 孩子按容量分组后立即递归，不生成全图所有层的 frontier；但显式 prefix lists 仍可能随结果数增长，不能据此声称总内存有界或适合巨型图。
- 只按完全相同的整数 P/X 分组，没有近似相似度、哈希碰撞风险、相近邻域公共部分提取或优化型子树调度。
- 合并要求固定图和相同局部顶点坐标，且原状态来自正确的 BK 所有权划分。代码不能被直接套到允许非邻居的 k-plex 或有其它路径约束的枚举。
- 小图测试不能替代一般正确性证明、真实图性能实验或对已有压缩/模块分解方法的新颖性核对。
